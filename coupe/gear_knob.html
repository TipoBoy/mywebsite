Richbrook 'Ball' Gear Knob

Part Number 3000.45

I'm slowly replacing as much of the interior as possible with aluminium items. The original leather gear knob has therefore been replaced with this Richbrook 'Ball' item which is anodised 'staybrite' aluminium in silver.

Since my car is a 5 speed the gear knob needs lifting for reverse. Thus the 'lift reverse' version of the gear knob needs ordering. This is basically the same as the standard item except that the neck is wider to allow the lift mechanism to raise into the bottom of the gear knob.

The existing gear knob is simply glued onto a spined shaft. Therefore to remove it just pull upwards. To fit the new gear knob you may need to wrap insulation tape around the spined shaft in order to increase it's diameter to match the gear knob. You should be able to get a good tight fit. The gear knob is held in place using a small grub screw from the dashboard side using a hex key.

The gear knob has no gear selector markings on it which is what I wanted. "Richbrook" is engraved one the base of the knob.
